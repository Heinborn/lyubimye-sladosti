# Конфетная лавка «Любимые сладости» (Якутск)

Сайт семейной конфетной лавки «Любимые сладости», работающей в Якутске более 20 лет.

- **Живая версия (GitHub Pages):** https://heinborn.github.io/lyubimye-sladosti/
- **Адрес лавки:** г. Якутск, ул. Рыдзинского, 24, ТЦ «Якутяночка», 1 этаж, правое крыло (ориентир — рынок «Манньыаттаах»)
- **Режим работы:** ежедневно с 09:00 до 19:00 (`Asia/Yakutsk`, UTC+9)
- **Телефон и WhatsApp:** +7 (914) 272-72-60

## Структура проекта

- `index.html` — полностью автономная версия сайта (все стили, скрипты и оптимизированные фотографии встроены внутри файла).
- `site/` — чистая модульная структура для размещения на домене `.ru`:
  - `site/index.html`
  - `site/css/styles.css`
  - `site/js/app.js`
  - `site/images/`
  - `site/robots.txt`
- `preview_desktop.jpg` и `preview_mobile.jpg` — превью готового сайта для просмотра на компьютере и телефоне.

## Быстрая настройка

Все контакты, график работы, юридические реквизиты и флаг показа сезонного новогоднего блока (`seasonal.enabled`) вынесены в единый объект `window.SITE_CONFIG` в самом начале `<body>` в `index.html` и `site/index.html`.
